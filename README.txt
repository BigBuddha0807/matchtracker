MATCHTRACKER E-JUGEND – iPhone-Web-App

Enthalten:
- index.html: App
- manifest.webmanifest + Icons: Home-Bildschirm-Installation
- sw.js: Offline-Cache (nach erstem Laden)

WICHTIG ZUR NUTZUNG AUF DEM IPHONE:
Für die Installation als PWA muss dieser Ordner über eine HTTPS-Adresse bereitgestellt werden (z.B. eigener Webspace oder GitHub Pages).
Dann auf dem iPhone in Safari öffnen -> Teilen -> Zum Home-Bildschirm.
Nach dem ersten vollständigen Laden kann die App offline genutzt werden.
Die Daten werden lokal im Browser auf diesem iPhone gespeichert. Browserdaten nicht löschen, wenn du Spielerkader/Berichte behalten möchtest.

Timer:
- Zwei Halbzeiten à 25:00
- Start/Pause/Fortsetzen
- Bei 0:00 automatische Halbzeitmeldung bzw. Spielende
- Nach Halbzeit 1 erscheint die Schaltfläche „2. Halbzeit starten“. Damit wird die zweite 25-Minuten-Halbzeit vorbereitet; anschließend Start drücken.
